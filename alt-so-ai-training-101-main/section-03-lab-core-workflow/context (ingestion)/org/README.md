# Context Ingestion — `org/` Folder

This folder is where you will create your structured context files during **Step 2** of the lab.

## Your Goal

Using GitHub Copilot in Agent mode, you will generate **three files** in this folder by distilling and synthesizing the raw materials provided in `raw-materials/`.

---

## Target Files

| File | Source | Description |
|---|---|---|
| `overview.md` | `raw-materials/01 Marys Place Organization.md` | Clean, structured summary of Mary's Place — mission, vision, values, and organizational goals |
| `challenges.md` | `raw-materials/02 Marys Place Current Challenges.md` | Distilled operational challenges organized by service area |
| `tech-opportunities.md` | `raw-materials/03 Intro Call with Marys Place.txt` | Technology opportunities, product concepts, and system-related priorities surfaced in the stakeholder call |

---

## What Good Output Looks Like

See `reference (examples)/briefs/01-healthcare-portal.md` for an example of how a well-structured, high-signal context document is organized — clear sections, concise bullets, and explicit problem framing.

Your output files do not need to match that format exactly; they are context summaries, not product briefs. But the same principles apply: **structured, scannable, and decision-relevant.**
